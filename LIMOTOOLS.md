# LimoTools 0.2.0

Отдельный экспериментальный клиент Limochat для Windows 10/11 x64 и Android 10+. Работает с существующим сервером https://81-90-31-167.sslip.io/ и его аккаунтами. Не является сервером и требует интернет.

## Настройки

Нажмите ✦ LimoTools (на Windows также Ctrl+Shift+L). Доступны свой цвет акцента, размер сообщений, компактные чаты, уменьшение анимаций и размытие превью. Настройки сохраняются только на этом устройстве. Размытие не является блокировкой приложения.

Для Google-входа откройте настройки клиента → «Войти через Google» → ссылку подтверждения. Подтвердите аккаунт в браузере и вернитесь в приложение. Одноразовый запрос действует до пяти минут; сессию создаёт существующий сервер. Также доступен обычный вход по юзернейму и паролю.

## Скачать и собрать

Actions → Build LimoTools APK and EXE → последний успешный запуск ветки client/limotools → Artifacts: LimoTools-Android-APK и LimoTools-Windows-EXE. Внутри ZIP находятся установщики.

Сборка: Python 3.12, затем `python client/prepare.py`; далее команды из native/README.md. Скрипт подготавливает нативные файлы в рабочей папке сборочной машины. Исходные ветки сохранены; изменения находятся только в новой ветке форка. Новые идентификаторы: io.limotools.app и io.limotools.desktop. Можно установить рядом с Limochat.

## Ограничения первой версии

APK тестовый, подписан debug-ключом CI; гарантированные обновления поверх прежней сборки требуют постоянного закрытого ключа. EXE без подписи издателя.

Android использует WebView: фоновые Web Push, демонстрация экрана и полноэкранное видео этой оболочкой не реализованы. Камера и микрофон запрашиваются при звонке; звонки в фоне требуют проверки на телефоне. Файлы выбираются системным диалогом; скачивание открывается в браузере и для закрытых файлов может требовать отдельного входа. Кнопка «Браузер» открывает обычный сайт с отдельной браузерной сессией.

Windows сохраняет изоляцию Electron, работу в трее и существующую обработку уведомлений. Фактические звонки, Google-вход и установка требуют проверки на устройствах; успешная CI-сборка не заменяет эту проверку. Дополнительные настройки клиента могут потребовать адаптации при изменении разметки сайта.

## Новое в 0.2.0 — 12 функций

1. Поиск по настройкам и инструментам.
2. Режим фокуса: скрывает истории и фоновые эффекты.
3. Размытие фото и видео внутри переписки.
4. Скрытие аватарок в списке чатов и сообщениях.
5. Монохромный режим.
6. Настройка скругления пузырьков.
7. Четыре семейства шрифтов (доступность округлого зависит от системы).
8. Межстрочный интервал.
9. Ширина переписки.
10. Личный блокнот с автосохранением.
11. До 20 шаблонов ответов: только вставка в черновик, без автоотправки.
12. Экспорт и импорт оформления через JSON-код с проверкой полей.

Блокнот и шаблоны общие для аккаунтов внутри клиента на устройстве. Экспорт настроек не содержит их, сессии, пароли или сообщения. Сброс дополнений их не удаляет. Дополнения применяются сразу; основные настройки после импорта применяются при перезапуске клиента.

Версия Android повышена до versionCode 2. Для установки поверх APK 0.1.0 нужен тот же сертификат подписи; CI использует временный debug-ключ, поэтому обновление поверх старой установки не гарантировано. Сохраните нужный код настроек и заметки до переустановки.
